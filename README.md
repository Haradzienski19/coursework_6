# ЛитОбзор
Веб-сервер для поиска книг и автоматического анализа отзывов. Собирает рецензии с Goodreads, Фантлаба и Лабиринта, определяет тональность, строит облака слов и выделяет ключевые темы.

## Требования
* Python 3.9+
* `pip`
* Интернет-соединение (для первой загрузки NLP-модели)

   cd my-diplom
